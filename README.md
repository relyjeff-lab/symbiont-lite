# 共生體一號 Lite - 全球第一個可複製的家庭版共生體

## 這是做什麼的
讓AI看我伸手前3秒，猜杯子會往哪裡倒，完成身體腦、世界腦、推理腦的第一次共生。

## 需要準備什麼
1. 手機一支
2. 電腦一台，能開網頁就好
3. 谷歌帳號一個

## 錄影清單
全部放在 資料夾：共生體一號

- 影片A_伸手沒碰到.mp4：30秒，手伸過去快碰到就停
- 影片B_真的碰倒了.mp4：30秒，手真的去碰，杯子往右倒
- 影片C_扶住沒倒.mp4：30秒，手去碰但扶住了

## 怎麼跑
1. 去谷歌搜尋 Colab，新增筆記本，改名叫 共生體一號Lite
2. 格子一：掛載雲端硬碟，載入身體腦小模型
3. 格子二：讀取影片A，預測下一秒，輸出 預測A.jpg
4. 格子三：用影片B和影片C對答案

## 三腦吵架
把 預測A.jpg 截圖，問推理腦：這是我伸手前3秒，身體腦預測往左倒，但真實是往右倒，哪裡看錯了？

## 成果
- 真實影片3個
- AI預測圖1張
- 糾正報告1份

這三個就是共生體一號的第一個可複製證據。
